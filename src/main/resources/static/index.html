Guía de sustentación

Secuencia sugerida: crear 3 compradores y perfiles; registrar un vendedor y sus productos; ingresar existencias físicas; comprar como cada comprador; pagar; despachar; devolver un artículo; consultar reportes; reiniciar y volver a iniciar sesión para comparar.

El pago está simulado mediante aprobación/rechazo. La devolución registra la referencia de reembolso; no realiza transferencia bancaria real.
